# Screen Specifications

## 1. Home

### Goal
Make the product feel personal and cinematic immediately.

### Desktop composition
- restrained navigation
- strong editorial heading
- recent viewings as artwork-first cards
- optional watchlist spotlight
- sparse personal pulse/statements
- avoid KPI tiles

### Mobile
- simplified heading
- recent viewings horizontal or two-column
- bottom navigation
- central Log action

### Signature
Subtle ambient pointer color can respond to currently hovered poster.

---

## 2. Library

### Goal
Browse hundreds/thousands of movies efficiently.

### Controls
- All
- Cinema
- Home
- Favorites
- Watchlist
- 9+
- year
- genre
- sort by watched date/title/rating/release

### Desktop
Poster grid. Utility over theatrics.

### Mobile
Two-column poster grid by default, with adaptive density.

### Motion
Only subtle card/filtered-layout motion. No heavy scroll choreography.

---

## 3. Unified Search / AI

### Goal
Fastest way to find anything or command the product.

### Entry
- click search
- `/`
- `⌘K`

### Placeholder
`Search your cinema or ask anything`

### Query stages
1. direct movie/person search
2. natural filtering
3. personal history query
4. recommendation
5. action

### Examples
- `Interstellar`
- `Mark Wahlberg`
- `Fincher I haven't seen`
- `dark thrillers under 2h`
- `what did I watch at the cinema in August?`
- `add the second one to my watchlist`

### Result rendering
Prefer movie grids/rows, stats blocks and action acknowledgements.

### Signature
Existing cards reflow as conversational refinements change filters.

---

## 4. Movie Page

### Goal
The emotional/product centerpiece.

### Above fold
- backdrop
- poster
- huge title
- year/runtime/genres/director
- IMDb
- YOU rating
- watched state
- favorite
- watchlist
- Log Viewing CTA

### Personal history
Clear section:
- dates
- cinema/home
- language
- rating
- rewatch

### Public details
- cast
- crew
- synopsis
- release data

### Signature
Library poster morphs into Movie Page poster.

Artwork palette subtly themes:
- backdrop haze
- accent
- active state
- pointer glow

---

## 5. Log Viewing

### Goal
Under 10 seconds for a normal log.

### Required inputs
- date
- cinema/home
- language
- optional rating
- rewatch

### UX
Desktop:
- compact modal/sheet

Mobile:
- bottom sheet

### Defaults
- date may default to today only when user is explicitly logging a new current viewing
- never invent dates during bulk import

### Rating
Precise `/10` interaction with keyboard/touch ergonomics.

---

## 6. Quick Add / Bulk Add

### Goal
Populate the first library quickly.

### Flow
- search actor/director/franchise/query
- multi-select posters
- Add to library
- optionally add watchlist/favorite where relevant
- watched status/details can be enriched later

### Key rule
Do not create fake viewing dates.

---

## 7. Stats

### Goal
Reveal the user's taste.

### Modules
- films watched
- total viewings
- cinema/home split
- average score
- monthly activity
- genres
- actors
- directors
- countries
- decades
- language
- rewatch rate

### Style
Editorial data storytelling.

No enterprise analytics dashboard visual language.

---

## 8. Login

### Goal
Secure and quiet.

- almost no marketing
- strong brand typography
- one elegant authentication panel
- dark cinematic field
- no excessive animation

This is a private tool, not a conversion funnel.
